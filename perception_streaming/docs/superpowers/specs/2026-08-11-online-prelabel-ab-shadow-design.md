# 在线预标注 A/B 影子验证设计

## 目标

将已完成离线验证的语义分割集成策略接入网页预标注流程，以影子 A/B 模式与当前 MPFormer 基线并行运行；通过独立 CVAT 任务和人工盲评确认质量收益后，再决定是否替换默认模型。

## 范围与非目标

- 范围：同一上传批次的 A/B 推理、独立 CVAT 任务、语义掩码转 CVAT 多边形、固定抽样盲评、运行可追溯与失败隔离。
- 非目标：本期不自动切换默认模型，不修改当前 MPFormer 基线参数，不将未验收的新训练权重上线。

## 架构

上传后的图片清单被冻结为一个批次。批次快照按相对路径排序，记录每张图片的 SHA-256、原始及规范化尺寸；快照只读。A、B 各自从快照创建输入副本，禁止修改快照或另一分支的文件。这样即使某分支跳过或删除错误输入，两边的评测集合仍可追溯且一致。

A 分支继续沿用当前 MPFormer 流程；B 分支运行已验证更优的 Alpha50 离线策略：水平翻转 TTA、768 与 832 多尺度融合。两条分支各自创建一个 CVAT 任务，均带有批次 ID 与分支名，但不共享标注数据。

```text
上传批次
  ├── A：MPFormer 基线 → CVAT 任务 A
  └── B：Alpha50 + flip TTA + 768/832 融合
             → 掩码工件 → 多边形 XML → CVAT 任务 B
                                      └── 固定随机抽样盲评
```

## B 分支契约

1. B 适配器加载 Alpha50 权重的 SHA-256、运行代码版本/容器镜像 digest、输入归一化、logit 融合、双尺度 resize 插值、水平翻转及回翻转、背景和置信度规则；运行清单写入这些不可变参数。
2. 映射快照必须记录 `source class ID → canonical name → CVAT label name`。采用两阶段门禁：创建任务前，验证 canonical mapping 与即将提交给 CVAT 的版本化标签定义；创建任务后，读取 A、B 两个 CVAT task 的实际标签 schema（名称、类型、属性）并再次对照 canonical mapping。未知类、背景、空掩码均有显式处理规则。
3. B 的 13 类语义掩码按类别拆分连通域，按像素面积过滤、使用指定简化算法与容差转换为多边形，并输出 CVAT Images 1.1 XML。导入前校验 XML 的图片名、尺寸、唯一性、标签和多边形坐标范围。
4. 原始掩码、逐图类别统计、XML 与清单放到独立运行目录；转换异常不得伪造成功。
5. 创建前的标签映射校验失败时不创建 B 任务；创建后的 schema 或 XML 校验失败时禁止导入 B，标记并清理该任务。绝不把数值 ID 直接当作可接受的标签契约。

## A/B 运行状态

- `baseline` 和 `candidate` 具有独立状态、日志、CVAT task/job ID 与输出目录。
- A、B 串行获取 GPU 队列；启动前检查 B 的权重、YOLOv5 运行时、CUDA、可用显存和输出磁盘空间。任一 B 门禁失败时只将 B 标记为不可运行，不启动影子任务。
- 一个分支失败不取消另一个分支；盲评只有两个分支都成功、XML 校验通过且使用同一有效图片清单时才开放。
- 批次 ID、分支 ID 和图片快照哈希作为幂等键。重复提交/刷新/恢复只能复用已有状态或显式重试失败分支；每次重试均记录 attempt。取消、导入失败或重试留下的 CVAT 任务必须标记为失败并可由受控清理任务删除，禁止产生未追踪的孤儿任务。
- 当前网页默认结果仍是 A。B 获胜只写入“候选默认”状态，绝不自动替换 A。

## 网页与人工盲评

- 预标注页面新增运行模式：`当前基线`、`A/B 影子验证`。
- 运行页只展示 A、B 的运行状态。盲评阶段通过独立匿名页面/代理读取抽样图像和已随机化的 `方案 X`、`方案 Y`；不展示 CVAT URL、任务名、模型版本、分支目录或其他可识别元数据。提交并揭示结果后，管理员才能查看两个 CVAT 任务链接。
- 从两边共同成功的图片中按固定随机种子抽取 30 张；批次小于 30 张时全量抽取。每张的 X/Y 映射与展示顺序被记录但在揭示前不可由评审 API 获取。
- 每张盲评记录 `X 更好`、`Y 更好`、`相当` 或 `无法判断`，以及漏标、误标、边界差、碎片多、类别错误等原因。每个评审者只能提交一次；首期要求一名指定评审者完成全部抽样，后续可扩展到双人评审与一致性分析。
- 有效样本定义为非“无法判断”的完成记录。若有效样本少于 24、B 胜出率未严格高于 A、或 B 胜出相对 A 未达到至少 20 个百分点，则结果为 `无结论`；否则标记 B 为“候选默认”。提交盲评后才揭示 X/Y 与 A/B 的对应关系并生成汇总。

## 验收

1. 同一批次从不可变快照创建两个独立 CVAT 任务，且两个任务的图片清单、顺序、哈希和尺寸一致。
2. B 运行记录可完整复现模型、代码/镜像、参数、输入清单与输出工件。
3. 盲评抽样与 X/Y 映射可重放，页面/API/任务名均不泄露模型身份，且结果可追溯到图片与任务。
4. A 或 B 任一分支失败时，另一分支结果仍可用；盲评被正确禁用；重试、取消和服务恢复不创建未追踪任务。
5. 测试覆盖损坏单图、分支不修改快照、标签/尺寸/XML 校验失败、匿名性、固定种子、重试幂等、孤儿清理、取消恢复与 B 资源门禁。
6. 全量自动化测试及新增 A/B、掩码导出、盲评测试通过。

## 风险

- 当前已验证的离线策略依赖本地 YOLOv5 分割运行时与权重路径；部署前必须验证其可访问性和 GPU 兼容性。
- 离线 13 类 ID 与现有 CVAT 映射若不一致，会造成错误标签；该检查必须在任务创建之前完成。
- A/B 的人工盲评评价质量，不等价于全量 mIoU；上线决策需保留盲评样本与结论。
